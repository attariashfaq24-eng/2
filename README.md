# Armor Making Mod (Fabric, Minecraft 26.2, client-side)

Keys: K = menu, V = mark what you look at, J = stop.

1. Press K, choose items + enchant levels, switch each wanted item ON.
2. In the menu choose "Mark as: <role>", close it, look at the villager, press V. Repeat for each role. Mark the anvil with role ANVIL.
3. Stand where every marked villager and the anvil are within ~4 blocks, put string in the inventory, press K -> START.

Build: push this folder to GitHub, the Actions tab builds the jar (artifact "armor-making-mod").
Needs Java 25. Requires Fabric Loader + Fabric API for 26.2.
